# Prompt V2 条件分支单路径编译

## 背景

Prompt V2 画布允许展示分支，但编译器之前使用拓扑排序。节点本身没有
`chat_types` 限制、只有边有条件时，未命中的分支节点也会作为独立根节点进入
最终 `messages`，导致视觉上像分支，实际却把多个分支拼在一起。

## 目标

- 画布可以保留多分支表达。
- `chat_types` 继续作为第一阶段条件模型。
- 编译时从入口节点沿当前条件只选择一条路径。
- 同一源节点在同一条件下只能有一条出边，避免歧义。
- WebUI 当前路径、节点高亮、连线高亮与编译器单路径语义一致。

## 非目标

- 不引入任意条件表达式 DSL。
- 不改变模板、运行时节点和 flow JSON 的基础结构。
- 不改变当前 group/private 之外的 Prompt V2 行为。

## 验收

- 边按 `chat_types` 分支时，private 编译不包含 group 分支节点。
- 边按 `chat_types` 分支时，group 编译不包含 private 分支节点。
- 保存或加载 flow 时，同一条件下多条出边会被拒绝。
- WebUI 使用选中路径判断当前节点和当前连线，而不是只看节点是否适用当前聊天类型。
