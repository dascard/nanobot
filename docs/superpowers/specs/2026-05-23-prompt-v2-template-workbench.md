# Prompt V2 模板工作台体验修复

## 背景

Prompt V2 模板页仍有明显后台工具体验问题：

- 左侧同时放资源树、运行时覆盖、画布控制、添加节点和路径顺序，首屏信息过载。
- 中间画布高度固定偏低，不能形成主工作区。
- 右侧编辑区和中间画布顶部、高度不一致。
- 滚动条风格没有覆盖到主要内部滚动区域。
- 鼠标滚轮缩放画布时仍可能触发页面滚动。

## 目标

- 将页面改成固定高度三栏工作台。
- 左侧只保留高频导航，低频操作折叠。
- 中间画布占满工作区高度。
- 右侧详情/编辑面板与画布顶部对齐，并使用内部滚动。
- 画布滚轮只控制缩放，不冒泡到页面滚动。

## 非目标

- 不重写 Prompt V2 数据模型和 API。
- 不改路由、模板 CRUD 行为和编排图存储格式。
- 不引入新的 UI 框架或状态管理库。

## 验收

- `prompt-v2-workbench` 在桌面端具备固定工作区高度。
- 左/中/右三栏顶部对齐，无水平溢出。
- 画布最小高度不低于 720px。
- wheel 事件使用 passive:false 原生监听，并阻止默认滚动。
- 主要内部滚动区域使用统一自定义滚动条。
