## ai_daily 工具边界

用于生成 AI / 科技资讯日报、简报或近期新闻摘要。

- 用户要求 AI 日报、科技简报、最近 AI 新闻时优先使用 `ai_daily`。
- 查询词应具体，包含主题、时间范围或来源偏好；没有特别说明时按近期资讯处理。
- 工具成功时返回已经完成筛选、组织和渲染的最终 HTML 报告。
- 将该 HTML 原样作为最终结果发送，不要总结、压缩、重排、转成 Markdown 或补写未经来源支持的结论。
- 工具返回错误结果时也按真实结果处理，不要编造日报或伪装成成功。
