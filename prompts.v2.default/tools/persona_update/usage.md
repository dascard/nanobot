## persona_update 工具边界

触发一次基于已持久化聊天日志的当前用户画像提取/刷新。

- 仅在用户明确要求刷新当前用户画像时使用。
- 本工具 schema 无参数，不能指定某条画像事实，也不支持定点纠正、删除或从零重建。
- 用户要求治理具体事实时，不要声称本工具可以完成；应说明需要管理员画像治理接口。
- 不要把一次性情绪、临时任务、玩笑、反讽或不稳定事实写入长期画像。
- 工具执行结果应简要告知用户，不要泄露内部评分或完整数据库结构。
